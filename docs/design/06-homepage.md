## 3. 區塊 → API 欄位對應

| 區塊 | `GET /v1/home` 欄位 | 顯示規則 |
| --- | --- | --- |
| 非官方標示 | `meta.disclaimer`（固定） | 頁首與頁尾都出現，不可被關閉 |
| 搜尋 | 送到 `GET /v1/search?q=` | 輸入 ≥ 2 字才查；無結果時顯示「回報找不到」連到 `POST /reports (reason=other)` |
| 本週重點 | `highlights[]`（≤ 3） | `line` 直接顯示；無資料時整塊隱藏，不放佔位文字 |
| 下一個大事件 | `next_exam` | `days_until` 顯示「剩 N 天」；當天顯示「今天」；`null` 時改顯示 `deadlines[0]`；年級切換記 `localStorage`，重新呼叫 `/v1/exams/{id}?grade=` |
| 快到期 | `deadlines[]`（14 天內、`confirmed`） | 依 `days_until` 升冪；卡片顯示對象與 `credibility` 徽章；≤ 2 天標紅 |
| 最新公告 | `latest_notices[]`（5 則，`fields=list`） | 有 `student.summary` 顯示學生摘要與「官方原文 ↗」；沒有就只顯示官方標題並標「官方原文」；`student.deadline_confidence='auto'` 不顯示截止日 |
| 快速入口 | `counts` | 卡片副標用 `counts.wiki_pages`、`counts.links` |
| 最近資源 | `recent_resources[]`（4 則） | 顯示 `contributor_display` 與 `license`；第一階段無資料時整塊隱藏 |
| 頁尾同步時間 | `last_crawl_at` | 「最後同步 MM/DD HH:mm」；超過 24 小時變黃色並加「資料可能不是最新」 |

## 4. 可信度徽章（全站共用）

| `credibility` | 徽章 | 色 |
| --- | --- | --- |
| `official` | ○ 官方原文 | 綠 `#1B7F4D` |
| `student_summary` | ● 學生整理 | 藍 `#1F5FBF` |
| `submission` | ◆ 學生投稿 | 紫 `#6B4FBB` |
| `unverified` / `is_stale` | ▲ 待確認 | 黃 `#B7791F`；不出現在首頁 |

配色依計畫書 §09：深藍 `#123B6D`＋淺藍 `#DCEBFF`＋白底；字體 `Noto Sans TC, system-ui`。

## 5. 首頁不放（計畫書明列）

即時鐘聲／上課倒數、大面積形象 Banner、需要登入才能看的內容、空白社群動態牆、跑馬燈。

## 6. 驗收（對應計畫書附錄 A）

- [ ] 首屏（375×667）可見：非官方標示、本週重點至少 1 則、段考倒數。
- [ ] `GET /v1/home` 回應 ≤ 30 KB、TTFB ≤ 200 ms（KV 命中）。
- [ ] 所有卡片有 `credibility` 徽章與來源連結。
- [ ] `deadlines` 無 `auto` 資料（自動化測試）。
- [ ] 斷網／API 失敗時顯示上次成功內容（Service Worker cache）＋「離線」提示，不顯示空白。
