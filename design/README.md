# FHJH.me 前端設計稿

三個可點的 HTML 原型，同一套資訊架構、三種視覺方向。從 [`mockups/index.html`](mockups/index.html) 進入。

| 版本 | 檔案 | 方向 |
| --- | --- | --- |
| A 資訊儀表板（建議第一版） | `mockups/v1-dashboard.html` | 白底深藍卡片，計畫書「學生工具」 |
| B 校刊編輯風 | `mockups/v2-editorial.html` | 襯線標題、報紙版面 |
| C 工具型 App | `mockups/v3-app.html` | 深色側欄，最不像官網 |

版本 A 另有內頁：`v1-exam.html`（段考中心）、`v1-notice.html`（公告四欄摘要）、`v1-wiki.html`（請假 Wiki）。

截圖在 `mockups/shots/`。內容取自復興實中官網近期公開公告，僅供版面討論。
